# devlog 인덱스

수행한 작업의 배경, 구현 판단, 확인 결과와 남은 한계를 기록합니다. 무엇이 관측이고
무엇이 해석이며 무엇이 작업자가 정한 값인지 각 기록에서 구분해 둡니다.

## 파일명 규칙

EarthThruTime3D의 `devlog/` 규칙을 따르고, 번호는 이 저장소에서 따로 셉니다.

- 작업 결과: `YYYYMMDD_{author}_{nnn}_{title}.md` — 작성자마다 001부터
- 계획 문서: `YYYYMMDD_{author}_P{nn}_{title}.md` — 작성자마다 P01부터
- author는 GitHub 계정 이름의 소문자, title은 영문 snake_case입니다.
- 다른 기록은 파일 링크나 "jikhanjung P01"처럼 작성자와 번호로 가리킵니다.
- 새 파일은 이 인덱스에 추가합니다.
